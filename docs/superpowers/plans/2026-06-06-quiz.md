# 臉型測驗 `/quiz` Plan

> REQUIRED SUB-SKILL: superpowers:subagent-driven-development.

**Goal:** 取代 `/quiz` placeholder，建設計稿臉型測驗：4 題單選（每選項含臉型線稿 SVG），算出臉型 → 推薦框型 + 推薦商品；結果存 `localStorage('nb:faceShape')`；並讓虛擬試戴自動帶入該結果。

**對齊既有系統：** 用 codebase 的 4 種 `FACE_SHAPES`（圓形/方形/橢圓/倒三角，`@/lib/schemas/product`）；推薦框型用既有 `getRecommendedFrames`、商品排序用 `scoreProduct`（`@/app/tryon/lib/face-recommendations`）。設計稿有 5 臉型（含 long），long 併入「橢圓」。

**前置：** worktree `.worktrees/feat/quiz`（origin/dev）。Commit trailer `Co-authored-by: Claude <claude@anthropic.com>`。worktree 無 node_modules 先 `pnpm install --frozen-lockfile`。

## Task 1: 測驗資料 + 選項 SVG
**Files:** `src/app/quiz/quiz-data.ts`（純資料/邏輯）、`src/app/quiz/FaceOptionIcon.tsx`（SVG 線稿）
- `quiz-data.ts`：
  - `QUIZ_QUESTIONS`：4 題，每題 `{ id, question, options: { label, svg, score: Partial<Record<FaceShape, number>> }[] }`（FaceShape = 圓形/方形/橢圓/倒三角）。score 由設計稿轉換（long→橢圓）：
    - Q1「臉長相對臉寬」：1:1→{圓形:2,方形:2}(svg balanced)；1.3:1→{橢圓:2,倒三角:1}(svg oval)；明顯偏長→{橢圓:3}(svg long)
    - Q2「下顎線條」：圓潤→{圓形:2,橢圓:1}(round_jaw)；稍尖下巴細→{倒三角:2,橢圓:1}(pointy_jaw)；明顯方正→{方形:3}(square_jaw)
    - Q3「額頭與下巴寬度」：額頭較寬→{倒三角:2}(wide_top)；差不多→{橢圓:2,方形:1,圓形:1}(balanced_width)；下巴較寬→{方形:1}(wide_bottom)
    - Q4「最寬位置」：顴骨中央→{橢圓:2,倒三角:1}(cheeks)；下顎兩側→{方形:2,圓形:1}(jaw_wide)；整體偏窄偏長→{橢圓:3}(narrow)
  - `computeFaceShape(answers: number[]): FaceShape`：累加各選項 score 到 4 桶，argmax；平手優先序 橢圓>圓形>方形>倒三角。
  - `FACE_SHAPE_INFO: Record<FaceShape,{ title, note }>`：title 如「圓形臉」，note 簡短建議（圓形→選有角度框型拉長線條；方形→圓潤框柔和下顎；橢圓→百搭；倒三角→下半較寬的框平衡比例）。
- `FaceOptionIcon.tsx`：`{ svg: string; className? }` → 依 svg key 渲染對應 `<svg viewBox="0 0 120 140" fill="none" stroke="currentColor" strokeWidth="2">` 內容（port 設計稿 QUIZ_FACE_SVG 的 ellipse/path：balanced/oval/long/round_jaw/pointy_jaw/square_jaw/wide_top/balanced_width/wide_bottom/cheeks/jaw_wide/narrow）。stroke currentColor。
typecheck/lint 後 commit。

- QuizClient.tsx（client）：
